# 1. 版本定位

v1.0 解决：

```text
Knowledge Service 从 0 到 1
```

v1.1 解决：

```text
Knowledge Service
    ↓
真实 RAGFlow
    ↓
可靠 Ingestion
    ↓
权限安全 Retrieval
    ↓
Secure Chat
```

v1.2 继续解决：

```text
知识有没有被正确管理？
        +
检索结果是否真的好？
        +
部分依赖故障时是否可信？
        +
管理员能否定位问题？
        +
Desktop 是否已经真正使用 Remote Knowledge？
```

因此 v1.2 定义为：

> **Knowledge Governance & Retrieval Quality**

```text
                         ┌─────────────────────┐
```

# 15. 默认 Fail-Closed

默认：

```text
retrieval_failure_policy = fail_closed
```

例如：

```text
KB-A success
KB-B timeout
```

则：

```http
503 Knowledge Retrieval Temporarily Unavailable
```

禁止 LLM 根据：

```text
不完整知识
```

生成一个看似完整的答案。

---

# 16. 可选 Degraded Mode

管理员可在 KnowledgeSet 配置：

```json
{
  "retrieval_failure_policy": "degraded"
}
```

此时允许：

```text
部分 KB 成功
```

但必须返回：

```text
status = degraded
```

Chat 必须明确向用户提示：

```text
部分知识源当前不可用，本回答基于可用知识生成。
```

不得静默。

默认仍然：

```text
fail_closed
```

# 73. v1.2 完成定义

> Knowledge Service 能够安全地连接 RAGFlow、管理文档版本和 ACL，并完成 Secure Retrieval / Chat。

> Knowledge Service 不仅能够“检索”，而且能够治理 Metadata、管理知识生命周期、量化检索质量、解释每次 Retrieval 的执行过程、发现并修复 RAGFlow 状态漂移，并以稳定 Remote API 正式支撑 Copilot Knowledge Desktop。

```text
v1.0
Knowledge Foundation

        ↓

Secure Knowledge Runtime

        ↓

v1.2
Governed Knowledge Platform
        +
Retrieval Quality Platform
        +
Production Application Backend
```

> **从“安全 RAG 后端”升级成“可治理、可评测、可诊断、可正式投入业务的企业知识平台”。**

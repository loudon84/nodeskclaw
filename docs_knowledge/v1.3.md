# 8. Source Identity Authority


# 9. SourceFile Unique Index 重构

当前：

```text
knowledge_base_id + file_name
```

唯一约束必须拆分。

Manual：

```text
UNIQUE (
  knowledge_base_id,
  file_name
)
WHERE
  connector_id IS NULL
  AND deleted_at IS NULL
```

Connector：

```text
UNIQUE (
  connector_id,
  external_object_id
)
WHERE
  connector_id IS NOT NULL
  AND deleted_at IS NULL
```

这是 v1.3 Schema P0。

# 37. Full Sync

流程：

```text
Connector
   ↓
Discover Page 1
   ↓
Persist Source Objects
   ↓
Discover Page 2
   ↓
...
   ↓
Discovery Completed
   ↓
Detect Missing Objects
```

只有：

```text
完整 Discovery 成功
```

以后才能做：

```text
Missing → Deleted
```

禁止：

```text
Discovery 中途失败
→ 把未扫描到的数据当删除
```

# 40. Unchanged

如果：

```text

```

但 Fetch 后：

```text

```

```text

```

```text

```

避免无意义 Re-Embedding。

```text

```

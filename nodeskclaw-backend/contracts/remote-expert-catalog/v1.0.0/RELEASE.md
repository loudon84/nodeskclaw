# Remote Expert Catalog Contract v1.0.0

Employee-facing catalog for ACP Desktop Compose. Requires `expert:invoke`. Identity is `expert_slug` as `agent_ref`. Unpublished or disabled experts are not listed. Unknown detail lookups return 404. Runtime not ready remains listed as `unavailable`. Does not include ExpertTeam or skill schemas. Consumer pin is sha256 of SHA256SUMS. No Git tag required.

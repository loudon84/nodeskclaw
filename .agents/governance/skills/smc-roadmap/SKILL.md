# SMC Local Roadmap

保持 `one Roadmap Item -> one Stage PRD`。

若存在中央 Work Package，本地 Roadmap Item 必须记录：
```yaml
feature_id:
work_package_id:
global_change_ids: []
external_dependencies: []
```

本地 Roadmap 不能宣告 Cross-Repo Feature DONE；只能产生可回写 Evidence。
